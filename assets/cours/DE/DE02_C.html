SE PRÉSENTER (1) : SICH VORSTELLEN
I. Les salutations (Begrüßungen)

Les salutations sont les premières expressions utilisées lorsqu’on rencontre une personne. Elles permettent de commencer une conversation de manière polie et correcte.

  • Hallo / Hi : Salut
  • Guten Morgen : Bonjour (le matin, jusqu'à 10h-11h)
  • Guten Tag : Bonjour (toute la journée)
  • Guten Abend : Bonsoir
  • Gute Nacht : Bonne nuit
Exemples de salutations
  • Hallo, Lehrer. → Bonjour, professeur.
  • Guten Morgen, mein Freund. → Bonjour, mon ami.
  • Guten Abend, Frau. → Bonsoir, Madame.
II. Dire son nom (Den Namen sagen)

Pour se présenter en allemand, il est important de savoir demander et dire son nom. On utilise souvent le verbe "heißen" (s'appeler) ou le verbe "sein" (être).

  • Wie heißt du? → Comment t'appelles-tu ?
  • Ich heiße… → Je m’appelle…
  • Mein Name ist… → Mon nom est…
  • Ich bin… → Je suis…
Exemples
  • Ich bin Soumahoro Siata. → Je suis Soumahoro Siata.
  • Ich heiße Konan Sylvain. → Je m’appelle Konan Sylvain.
  • Hallo, mein Name ist Aïcha. → Bonjour, mon nom est Aïcha.
III. Le nom et le prénom

En allemand, on distingue également le nom de famille du prénom.

  • Der Nachname / Familienname : Nom de famille
  • Der Vorname : Prénom
  • Der Spitzname : Surnom
Exemples
  • Mein Vorname ist Aminata. → Mon prénom est Aminata.
  • Mein Familienname ist Traoré. → Mon nom de famille est Traoré.
IV. Les déterminants possessifs (Possessivartikel)

Les déterminants possessifs servent à indiquer la possession. En allemand, ils s'accordent avec la personne qui possède.

  • Mein : mon / ma / mes
  • Dein : ton / ta / tes
  • Sein : son / sa / ses (pour un homme/masculin)
  • Ihr : son / sa / ses (pour une femme/féminin)
Exemples
  • Mein Name → Mon nom
  • Dein Name → Ton nom
  • Sein Name → Son nom (à lui)
  • Ihr Name → Son nom (à elle)
  • Meine Schwester → Ma sœur
  • Seine Freunde → Ses amis (à lui)
  • Ihre Freunde → Ses amis (à elle)

Remarque : On utilise sein si le possesseur est masculin et ihr si le possesseur est féminin.

Exemple : Wie heißt deine Schwester? → Ihr Name ist Konan Mélanie.

V. Les pronoms interrogatifs (Fragewörter)

Les pronoms interrogatifs commencent presque tous par la lettre "W" en allemand.

  • Was : que / quoi / quel
  • Wo : où
  • Wer : qui
  • Wann : quand
  • Warum : pourquoi
  • Wie : comment
  • Wie viele : combien
Exemples
  • Wie heißt du? → Comment t'appelles-tu ?
  • Woher kommst du? → D’où viens-tu ?
  • Wie geht es dir? → Comment vas-tu ?
VI. Exercices d’application

Exercice 1 : Complète les phrases (en allemand)

  1. Hallo, mein ______ ist Mariam.
  2. Wie ______ du? (verbe s'appeler)
  3. Mein ______ ist Traoré (nom de famille).

Exercice 2 : Traduis en français

  1. Guten Morgen, mein Lehrer.
  2. Ich heiße Yao.
  3. Ihr Name ist Aminata.

Exercice 3 : Traduis en allemand

  1. Je m’appelle Adama.
  2. Quel est ton nom ? (ou Comment t'appelles-tu ?)
  3. Ma sœur s’appelle Aïssata.

Exercice 4 : Réponds aux questions (en allemand)

  1. Wie heißt du?
  2. Wie ist dein Vorname?
  3. Wie ist dein Familienname?
Conclusion

Se présenter en allemand est la base de toute communication. En maîtrisant les salutations, le verbe "heißen", les possessifs et les mots en "W", tu peux facilement échanger tes premières informations avec un correspondant allemand.
