GROUPES NOMINAUX & POSSESSION EN ALLEMAND
I. Les mots composés (Komposita) : La magie de coller les mots

En allemand, quand on veut parler d'un objet qui appartient à une catégorie, on ne fait pas de longue phrase, on **colle les mots**. Hausaufgaben.

Règle d'or : Le dernier mot donne le genre (der/die/das) à tout le groupe.
  • Haus (maison) + Aufgaben (devoirs) = Hausaufgaben (devoirs de maison)
  • Klasse (classe) + Zimmer (chambre/salle) = Klassenzimmer (salle de classe)
  • Deutsch (allemand) + Buch (livre) = Deutschbuch (livre d'allemand)
  • Schule (école) + Tasche (sac) = Schultasche (sac d'école / cartable)
II. L'ordre dans le groupe nominal

Comme en anglais, l'adjectif se place avant le nom.

  • ein Buch → un livre
  • ein großes Haus → une grande maison
  • meine kleine Tasche → mon petit sac
  • das rote Auto → la voiture rouge
IV. Le génitif (Exprimer la possession avec un nom propre)

Pour dire "le livre de Ali", on ajoute simplement un -s au nom de la personne, sans apostrophe !

Structure : Nom de la personne + s + objet
  • Alis Buch → le livre d'Ali
  • Marias Schultasche → le sac d'école de Maria
  • Monikas Vater → le père de Monika
VI. Exercices d’application

Exercice 1 : Colle les mots pour former un mot composé

  1. Schule + Tasche = ____________
  2. Haus + Aufgaben = ____________
  3. Deutsch + Lehrer = ____________

Exercice 2 : Traduis en utilisant le -s de possession (Génitif)

  1. Le livre de Sylvain → ____________
  2. Le sac de Fanta → ____________
  3. Le nom de Ali → ____________

Exercice 3 : Complète avec mein / sein / ihr

  1. Das ist Maria. Das ist ______ Buch. (C'est son livre à elle)
  2. Das ist Ali. Das ist ______ Kuli. (C'est son stylo à lui)
  3. Ich bin ein Schüler. Das ist ______ Schule. (C'est mon école)
Exercice spécial

Cet exercice mélange les deux notions : l'ajout du -s au nom propre et la création de mots composés (mots collés).

Partie A : Traduis en Français (Allemand → Français)

  1. Silvains Deutschbuch → ___________________________
  2. Aichas Schultasche → ___________________________
  3. Konans Hausaufgaben → ___________________________
  4. Annas Klassenzimmer → ___________________________
  5. Marias Kinderbuch → ___________________________

Partie B : Traduis en Allemand (Français → Allemand)

Astuce : En allemand, on met le nom de la personne en premier avec un "s".

  1. Le livre d'école de Sylvain → ___________________________
  2. Le sac de maison de Fanta (sac pour la maison) → ___________________________
  3. Le professeur d'allemand d'Ali → ___________________________
  4. Les devoirs de Maria → ___________________________
  5. La salle de classe de Konan → ___________________________
